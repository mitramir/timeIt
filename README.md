# 📚 Book Listing App

This project is a full-stack application for listing books with support for barcode scanning to easily add books to the list.

## 🚀 Overview

The application consists of:

- **Backend**: Built with **Node.js**, providing a RESTful API to manage products(books).
- **Database**: Uses **MongoDB** for storing book data.
- **Frontend**: A mobile application developed with **React Native** using **Expo**.
- **Scanner Component**: Allows users to scan the barcode (ISBN) of books to fetch or add book details quickly.

## 🛠️ Features

- List books with details such as title, author, and ISBN
- Scan book barcodes to retrieve or register them
- Responsive mobile interface using Expo

## 📦 Tech Stack

| Layer    | Technology                   |
| -------- | ---------------------------- |
| Backend  | Node.js, Express             |
| Database | MongoDB                      |
| Frontend | React Native (Expo)          |
| Scanning | Expo Camera & BarcodeScanner |
